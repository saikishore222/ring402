ring402

x402 is an open standard for APIs that charge per request. The API answers "402 Payment Required", the caller pays, and then it gets the data. On Solana that payment is a normal public transfer, so anyone can see what an API charges, what it earns and what each customer spends.

ring402 pays with a confidential transfer on Privacy Rings instead. Anyone can still see who paid whom, but only the seller can read the amount and the token. Every request on this page is a real payment on Solana devnet, the test network.
